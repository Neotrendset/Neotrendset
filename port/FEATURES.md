# 기능 연결표

기준은 RomForge v1.9.1의 도구 목록과 소스입니다. 아래 기능은 원본 엔진을 사용합니다. UI는 Avalonia의 입력 폼·편집 목록·선택 대화상자로 다시 구성했습니다. “연결”은 코드와 실행 경로가 있다는 뜻이며 모든 실물 게임에서 검증했다는 뜻은 아닙니다.

| 영역 | 연결한 기능 | 이번 검증 |
|---|---|---|
| 일반 패치 | IPS/BPS/UPS/PPF/APS/xdelta/DCP, 연속 패치, 출력 이름, 원본 해시, 압축 안 원본 선택 | IPS 엔진 및 화면 명령의 실제 출력 비교, xdelta native 왕복 |
| 아케이드 | 원본·패치 목록 매칭, 수동 지정, 일괄 실행 | 화면 생성; 실제 세트 미검증 |
| Vita | PKG/폴더 입력, 라이선스·패치 처리, 목록 편집 | PARAM.SFO 호환성; 실제 게임 미검증 |
| PC-98 | 원본·패치 입력과 적용 | 화면 생성; 실제 이미지 미검증 |
| 압축·해제 | 원본 지원 형식의 압축·해제, ZIP/7z 입력, 취소·로그 | 암호화 솔리드 7z, CSO/ZSO/ZCCI/RVZ/CHD 왕복 |
| 디스크 형식 변환 | 원본 CD·CHD·Wii/GC 변환 경로와 옵션 | CHD 및 GC RVZ 합성 이미지 왕복 |
| Switch 리팩 | NSP/NSZ/XCI/XCZ 목록, 메타데이터·언어·아이콘, ID·언어 강제, 추출/리팩/전체 작업 | PFS0 생성; 사용자 키를 쓰는 실제 리팩 미검증 |
| Switch 병합·분리 | 원본 파일 목록 기반 병합·분리, 옵션 | 화면·실행 연결; 실제 게임 미검증 |
| Switch 변환 | NSP/NSZ/XCI/XCZ 변환, 압축 옵션 | 화면·원본 엔진 연결; 실제 게임 미검증 |
| Switch 새턴 → NSP | CUE/CHD 입력, 표지·기본 NSP, 변환 | 화면 연결; 실제 기본 NSP 미검증 |
| Switch 버전 요구 변경 | 파일 목록 기반 키 세대/버전 요구 변경 | 화면·원본 엔진 연결; 사용자 키 경로 미검증 |
| Switch 패치 | 개별 경로·암호, 타이틀 ID별 폴더/압축 일괄 지정, 선택 패치 해제 | UI 연결; 실제 타이틀 패치 미검증 |
| Wii U | 리팩, 타이틀 역할·패치 경로, 폴더/WUA 변환 | WUA 생성·읽기 데이터 일치 |
| Wii | 추출·패치·리팩, 출력 옵션 | 원본 엔진 연결; 실제 Wii 타이틀 미검증 |
| 3DS 리팩 | CIA/CCI/NCCH, ExeFS/RomFS, 추출·패치·재빌드 | ExeFS/RomFS 생성·해시·파일 데이터 일치 |
| 3DS SD | SD·movable 입력, 설치 게임 조회·추출, 새 설치, DB 복구 | 상위 설정과 하위 도구 UI 연결; 실제 SD 미검증 |
| 3DS 변환·복호화 | CIA/CCI/ZCCI 변환 및 복호화 경로 | NCSD/ZCCI 왕복; 암호화 실제 게임 미검증 |
| PS / PSP | PBP 패킹·언팩, 다중 디스크, 이미지, BGM 미리듣기·탐색, POPS 옵션, CSO/ZSO 변환 | PBP, CSO, ZSO 왕복 및 PNG 처리 |
| 해시·CUE·인증서 | 원본 알고리즘 선택, 파일 목록, CUE 도구, CIA 인증서 추출 | BLAKE3 표준 벡터; 화면 생성 |
| 티스토리 첨부파일 | URL·첨부파일 목록·다운로드·저장 위치 | 화면 연결; 외부 사이트 다운로드 미검증 |
| 디스크 이미지 | 외장 디스크 검색, 이미지 읽기·쓰기, ZIP/분할 옵션, 취소 | macOS diskutil/원시 디스크 연결; 실제 장치 I/O 미검증 |
| 설정 | 일반·패치·압축·PS/PSP, 효과음, 항상 위, 원본 업데이트 확인 | 화면·저장 경로 연결; 모든 설정 조합 미검증 |
| Container Inspector | NCSD 8개 파티션, NCCH ID/Product Code·ExeFS/RomFS, CIA 구역 위치, ExeFS 10개 엔트리, SHA-256, JSON | 경계·중첩·암호화·취소·JSON 등 26개, 변형 헤더 1,200개 |

원본 WPF 전용 창 장식·작업 표시줄 통합·드라이브 문자 지정은 macOS 창·진행 표시·마운트 경로로 바뀌었습니다. Intel Mac 및 Windows 빌드는 이번 배포 대상이 아닙니다.
